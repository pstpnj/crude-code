# Terminal Agent Simulator

A fictional portrayal of an AI coding agent at work.

## Language

**Terminal agent simulator**:
A display of fictional coding activity, including commands, thinking pauses, and results. Its displayed commands do not execute.
_Avoid_: Real agent, command runner

**Task sequence**:
A fictional coding task that progresses from project inspection through edits and tests to completion.
_Avoid_: Actual work, live task
